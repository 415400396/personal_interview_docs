## 2. 已确认迁移的核心成果

- 181 日、7,829,793 行原始数据审计；
- 4,193,162 条正式样本和精确日期切分；
- 318,499 条、228 城公平同工单；
- MAE 126.84 → 123.91（-2.30%）；
- RMSE 202.75 → 198.03；
- Spearman 0.4965 → 0.5280；
- 196/228 城 MAE 改善；
- 2 小时以上桶改善、30–60 分钟桶退化 6.03 分钟；
- 115 → 35 → 87 维的消融与特征增量结论；
- 新增特征整体 permutation 后 MAE +7.53 分钟；
- 城市拆模只改善约 0.1165 分钟，最终未采用；
- 87 维、536 树 CPU 模型，99/99 验证通过；
- 同一特征向量线上/本地只差约 0.399 分钟；
- 217 城、62 天、347,292 行小时级评估集；
- Label 语义迁移造成 MAE 75.60 假提升的完整判断；
- 随机切分、复杂损失和城市拆模等负结果；
- 正式严格目标未全面达到、上线前后不能直接作因果结论。

这些内容不影响解释项目的业务价值、技术判断、指标口径和本人贡献。未来若发现原文中仍有独有且合规的重要事实，应把事实脱敏写入对应指标卡，而不是重新提交整份原文。
