# 六周系统复习路线

适合边投递边准备。每周都要同时推进“项目、知识、编码、投递”四条线，避免学了很久却没有面试产出。

本文件定义知识顺序；每周行为交付和编码题量以[三个月能力改善计划](05-三个月能力改善计划.md)为准。七天启动是临近面试时的替代冲刺，不与正常第一周任务叠加。

## 第 1 周：项目夺回与事实收口

目标：任何数字都说得清，任何边界都不夸大。

- 临近面试时可用七天启动计划替代本周安排；正常节奏不额外叠加；
- 优先完成一个主项目的 2 分钟与 10 分钟讲解，其余两个在第一个月分周补齐；
- 事实台账中的 C/X 级说法逐条确认或删除；
- 从服务器只补脱敏实验表和数据口径；
- 模拟面试 1 次；
- Python/算法题按统一计划的第 1 周配额执行。

验收：连续追问 15 分钟不需要回公司代码查基本事实。

## 第 2 周：Agent Runtime 与工具可靠性

目标：能设计受控、可恢复的 Agent，而非只背框架。

- Workflow/ReAct/Plan-and-Execute/Router；
- Tool Schema、发现、路由、权限、超时、重试、幂等；
- MCP 和普通 API/Function Calling/Skill 的边界；
- 显式状态、checkpoint、暂停恢复、终止条件；
- 按统一计划继续并验收个人 Agent 作品 A1；
- 模拟系统设计 2 次。

验收：给一个新业务场景，30 分钟内画出正常、失败和人审路径。

## 第 3 周：Context、Memory、RAG

目标：不把所有信息都塞进 Prompt，不把所有检索都叫 RAG。

- Context 选择、压缩、摘要、来源、时效与预算；
- Memory 写入门控、召回、更新、冲突、遗忘和隐私；
- RAG 的 ingestion、chunk、hybrid retrieval、rerank、context packing；
- 检索指标和答案指标分离；
- 个人作品加入小型知识库和引用；
- Python/算法题按统一计划的第 3 周配额执行。

验收：能诊断召回错、排序错、上下文组装错和生成错四类问题。

## 第 4 周：Eval、观测与安全

目标：能回答“怎样证明 Agent 真的变好”。

- Golden Set、轨迹评分、规则评测、人评和 Judge 校准；
- Prompt/模型/工具/知识版本；
- Trace、错误 taxonomy、成本与延迟分位数；
- Prompt Injection、越权、PII、工具白名单、Sandbox；
- shadow、灰度、回滚和人工升级；
- 个人作品加入离线 Eval 和回放报告。

验收：每个设计决策都有指标，每个高风险动作都有阻断点。

## 第 5 周：Applied ML 与生产后端

目标：恢复自己已有的第二优势，避免 Agent 岗后端追问失分。

- 样本/标签、数据泄漏、偏差方差、长尾、漂移和校准；
- MAE/RMSE/AUC/F1/NDCG/Spearman 的适用场景；
- 树模型、特征重要性、SHAP/permutation；
- MySQL、Redis、MQ、事务、并发、限流、熔断、降级；
- 时效与阈值各做一次 30 分钟深挖；
- 完成一轮 LRU、Top-K、并发和 SQL 场景题。

验收：能从离线实验讲到线上服务和业务效果，不混淆三层指标。

## 第 6 周：LLM 基础、定向补课与面试循环

目标：达到应用岗够用的模型原理深度，并形成稳定面试节奏。

- Transformer、Attention、位置编码、Norm、KV Cache、GQA/MoE；
- SFT/LoRA/DPO/PPO/GRPO 到 L2；
- 根据 A 档 JD 做 3 份定制项目排序和关键词；
- 完成个人 Agent 作品 README、架构图、评测报告；
- 进行 2–3 次全真模拟；
- 每次真实面试 24 小时内复盘并更新题库。

验收：能诚实回答没做过的训练技术，同时把话题带回已有生产证据。

## 每周节奏

| 动作 | 最低频率 |
|---|---:|
| 项目口述 | 3 次 |
| Python/算法题 | 按三个月计划统一排期，不另加题量 |
| 系统设计 | 2 题 |
| 模拟面试 | 1 次 |
| 精读 JD 并评分 | 5 个 |
| 定制投递 | 根据市场，宁缺毋滥 |
| 周复盘 | 1 次 |

## 根据真实面试动态调权

- 项目讲不清：下一周优先项目，不继续扩知识面；
- 编码连续失败：每天固定 60–90 分钟，先恢复模板和调试；
- RAG/Agent 概念会背但不会设计：减少阅读，改做白板题和作品；
- 后端追问频繁失分：把 MySQL/Redis/MQ 提到 25%；
- 算法岗机会明显增多：再提高 ML/LLM 原理和 PyTorch 手写；
- JD 以训练/RL 为主体：先判断岗位是否值得转型，不临时把六周计划全部推翻。
