# 七天启动计划

用途：在开始密集投递前，用一周把项目表达、Agent 主干、RAG/Eval、后端和编码恢复到能面试的状态。

这是临近面试时的短期冲刺方案；选择它时，用本文件替代[三个月能力改善计划](05-三个月能力改善计划.md)的正常第一周，不把两套任务叠加。完成的算法题计入前六周总量。

默认每天 5 小时左右；如果只有 3 小时，完成每天下方的“最低交付”。

## Day 1：统一叙事与 Agent 边界

学习：

- Workflow、Router、ReAct、Plan-and-Execute 的差异；
- 什么任务需要 Agent，什么任务固定 Workflow 更可靠；
- LLM、工具、规则、人审和状态分别负责什么。

项目：

- 无笔记讲一遍职业经历 2 分钟版；
- 画阈值系统的正常链路、拒绝链路和执行失败链路；
- 准备“为什么不让 LLM 直接写 SQL”。

编码：HashMap、滑动窗口各 1 题；用 Python 写并口述复杂度。

最低交付：一张阈值系统图 + 90 秒录音 + 2 道题。

## Day 2：Tool、Function Calling、MCP 与 Skills

学习：

- Tool Schema 怎样减少歧义；
- 参数错误、超时、重试、幂等、权限和结果过大；
- Function Calling 是模型接口，MCP 是工具接入协议，Skill 是可复用任务方法；
- 为什么工具越多不一定越好，怎样路由和分组。

项目：

- 为城市诊断设计 5 个只读工具；
- 每个工具写输入、输出、权限、超时、错误类型和可观测字段；
- 把阈值系统的“外部结构化输入”与 LLM 输入信任边界讲清。

编码：树的 DFS/BFS 各 1 题。

最低交付：一页 Tool Contract + 2 道题。

## Day 3：Context、Memory 与 Harness

学习：

- Prompt、Context、Memory、RAG 的边界；
- 工作记忆、情景记忆、语义记忆、程序性记忆；
- 上下文预算、摘要、相关性选择、来源与时效；
- Harness 如何管理 Agent Loop、状态、工具、权限、回放和评测。

项目：

- 设计城市诊断状态对象；
- 写出上下文装配顺序与 Token 预算；
- 回答“错误记忆怎样污染系统”和“审批后怎样恢复”。

编码：链表、堆/Top-K 各 1 题。

最低交付：一张 Context 装配图 + 一个状态 Schema + 2 道题。

## Day 4：RAG 全链路

学习：

- 文档解析、切片、Embedding、稀疏/稠密混合召回、过滤、Rerank、上下文组装；
- Parent-child、Query Rewrite、Metadata Filter；
- Recall@K、MRR/NDCG 与生成答案正确性为什么要分开评估；
- 知识更新、权限过滤和引用溯源。

项目：

- 明确阈值项目的实体知识查询为什么“属于知识增强”，但不等于做过完整向量 RAG；
- 如果升级成文档知识库，画出检索与评测链路；
- 准备一个召回对但回答错、一个召回错导致回答错的 Badcase。

编码：二分、Top-K 各 1 题。

最低交付：一张 RAG 图 + 一张分阶段指标表 + 2 道题。

## Day 5：Agent Eval 与可观测性

学习：

- 最终任务成功率、步骤正确率、工具选择、参数正确率、轨迹效率；
- Golden Set、回归集、人评、规则评分和 LLM-as-Judge 校准；
- Trace 怎样连接 prompt/model/tool/state/result；
- 错误分类、版本对比、线上 shadow、灰度与回滚。

项目：

- 用阈值系统 42 条金标解释“格式正确不等于业务正确”；
- 为城市诊断设计离线评测，不虚构已上线数据；
- 为时效模型区分离线模型指标、线上服务指标和业务动作指标。

编码：动态规划基础 2 题。

最低交付：三项目各一张指标树 + 2 道题。

## Day 6：后端、可靠性与时效项目

学习：

- MySQL 索引、事务隔离、锁与大批量写；
- Redis 缓存一致性、穿透/击穿/雪崩；
- MQ 至少一次、幂等、重试、死信和顺序；
- SSE/流式响应、超时、限流、熔断和降级。

项目：

- 10 分钟讲时效项目，重点是 Label、OOT、同工单、分桶取舍和线上一致性；
- 复盘阈值系统“审批成功但写库失败”与超长 SQL，明确当前已定位和未完成部分；
- 设计可靠的 callback → outbox/MQ → worker → final status 链路。

编码：LRU 或并发生产者/消费者 1 题，加 Hot100 1 题。

最低交付：一次时效项目录音 + 一张可靠执行状态图 + 2 道题。

## Day 7：LLM 基础与全真模拟

学习：

- Transformer、Self-Attention、位置编码、Pre/Post Norm；
- MHA/MQA/GQA、KV Cache、MoE 的目的与取舍；
- SFT、LoRA/QLoRA、DPO、PPO、GRPO 的目标和边界；
- 为什么自己的阈值问题优先用 Prompt + 规则 + Eval，而非先微调。

模拟：

- 2 分钟自我介绍；
- 阈值系统 15 分钟深挖；
- 时效项目 15 分钟深挖；
- Agent 系统设计 20 分钟；
- Python 编码 30 分钟；
- 行为面与反问 15 分钟。

最低交付：完成一次 90 分钟模拟并填写面试复盘模板。

## 每日固定动作

- 开始前：写下今天唯一的关键输出；
- 学习后：合上资料，用 3 分钟解释；
- 项目后：记录一个说不清或证据不足的点；
- 编码后：写复杂度、边界测试和另一种解法；
- 结束前：更新 `tracking/02-复习进度.md`。

## 七天结束验收

- 三个项目都能讲 30 秒、2 分钟和 10 分钟；
- 事实数字与 `docs/evidence/` 一致；
- 至少完成 14 道 Python 题；
- 能从零设计一个带状态、工具、Eval、安全和降级的 Agent；
- 能解释 RAG 分阶段评测；
- 能回答数据库、缓存、MQ、幂等的基础系统题；
- 完成一次全真模拟并产生下一周缺口列表。
