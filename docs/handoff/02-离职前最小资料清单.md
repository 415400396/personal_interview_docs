# 离职前最小资料清单

目标不是复制训练服务器或公司项目，而是在合规前提下，留下足以解释本人工作和复现实验思路的脱敏事实。

## 1. 时效预测：服务器上最值得补的内容

优先级从高到低：

### 必须尽量补

- 最终 Label 定义：起点、终点、过滤条件、异常值和取消/重开工单处理；
- 数据时间范围、独立工单数、原始行数、城市数及去重规则；
- train/validation/test 的日期切分；
- 特征清单的“业务分组版”：车辆、电量、工单、供需、空间、时间、实时统计等，不需要内部字段名；
- 最终模型超参数与训练目标；
- 基线和最终模型在同样本上的总指标、分桶指标和分城摘要；
- 至少两个失败实验及结论，例如标签语义迁移、随机切分过乐观、城市拆模收益不足；
- 线上输入向量如何与离线对齐、缺失值含义、输出单位和截断/边界；
- 一份脱敏实验表，能说明“为什么选择最终方案”。

### 有则更好

- 特征重要性或 SHAP 的稳定结论，而不是完整图片；
- 训练时长、数据读取瓶颈、CPU/GPU 对比；
- 线上覆盖、调用量、P95/P99 和业务指标，但必须是允许保留的聚合数据；
- 模型卡：版本日期、训练数据窗口、依赖、限制和回滚条件。

### 不必整包复制

- 全部训练代码、Notebook 历史版本和 checkpoint；
- 大体量 parquet/CSV、模型二进制和缓存；
- 重复的调参日志；
- 仅服务于公司环境的发布脚本和配置。

只有当训练代码里存在“文档无法还原的关键逻辑”时，才把该逻辑脱敏改写成伪代码或公式。例如 Label 构造、严格时间窗口、同工单匹配、样本权重和指标计算值得保留；通用 XGBoost `fit/predict` 不值得。

## 2. Hive/SQL：保留逻辑，不搬内部资产

值得转写：

- 数据血缘图：每类业务事实从哪里来、怎样聚合、在哪个时间截点可用；
- 关键 CTE 的意图：工单选择、事件配对、时间窗统计、去重、负样本/异常过滤；
- 防泄漏规则：每个特征只能使用预测时刻之前的信息；
- 粒度转换：明细行 → 工单快照 → 训练样本；
- 数据质量检查：重复率、空值率、时间逆序、口径漂移和分区完整性；
- 关键指标公式及分母为零、缺失城市、跨天等边界。

不要复制：

- 真实库表名、集群名、账号、队列、内部 URL；
- 完整生产 SQL 和调度脚本；
- 经纬度、车辆 ID、工单 ID、员工信息或真实样本；
- 能推断公司规模、策略阈值或内部组织的信息；
- AccessKey、Token、Cookie、数据库连接串或日志上下文。

推荐用如下脱敏形式保存：

```text
fact_work_order       工单生命周期与优先级
fact_vehicle_event    车辆关键事件流
snapshot_vehicle      预测时刻车辆状态
agg_city_supply       城市/区域历史供需统计

sample_time = 工单派发时刻
label = sample_time 到首个合法目标事件的分钟数
所有 rolling 特征的 event_time 必须 < sample_time
```

## 3. 阈值系统：优先补业务结果

现有工程和离线评测证据已经较完整，离职前最缺的是：

- 实际覆盖城市/运营区和活跃使用者数量；
- 每日/每周查询、修改、审批数量；
- 从人工操作到系统操作的耗时变化；
- 解析失败、用户取消、审批拒绝、执行失败的漏斗；
- 最终部署模型和参数、生产 P50/P95；
- 典型 Badcase 数量和修复前后回归结果；
- 执行成功后真实业务指标是否有可归因变化。

这些应向负责人申请脱敏聚合结果。拿不到时留空，不能凭印象估算。

## 4. 城市诊断 Agent：现状已固化，原始资产非必需

截至 2026-09-04 的代码与材料审计只证明结构化阈值建议接入、审批和确定性动作底座；未发现已经上线的完整异常发现、多步诊断、数据工具和效果学习闭环。完整下一阶段方案已经脱敏保存在 `docs/city-agent/`，未来不依赖原公司源码也能继续设计或用合成数据实现。

如果离职前发现另一个已经授权且可证明的实现来源，只需要补以下脱敏事实，不复制原始资产：

- Hive/MCP 工具实现；
- 多步诊断 Workflow 或状态结构；
- 真实工具调用 Trace；
- 离线诊断题集与专家标注；
- 城市异常识别报告；
- 建议进入 BPM 的审计记录；
- 调整后效果回看。

如果都不存在，该项目继续按“基于现有底座完成系统设计”保留；不要为凑 Agent 项目而补写虚构实现。后续可按 `docs/city-agent/05-实施路线图与运维手册.md` 建设个人合成数据作品。
